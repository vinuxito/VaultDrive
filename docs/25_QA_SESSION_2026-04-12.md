## Code Fixes (Committed in 75d3fa5 and follow-up)

### middleware_ratelimit.go
Added `isLoopbackIP()` bypass so E2E tests running on localhost don't exhaust rate limits:

```go
func isLoopbackIP(ip string) bool {
    host := ip
    if h, _, err := net.SplitHostPort(ip); err == nil {
        host = h
    }
    parsed := net.ParseIP(host)
    return parsed != nil && parsed.IsLoopback()
}
```

Applied to `middlewareRateLimitLogin` and `middlewareRateLimitPIN`. `middlewareRateLimit`
(global 100/min) intentionally NOT bypassed — it won't be hit by the test suite.

### handle_user_create.go
- Changed all `http.Error()` calls to `respondWithError()` so errors are always JSON
- Affects: decode error (400), password hash error (500), RSA key gen (500), private key
  encrypt (500), DB insert (500) — all five paths now consistent

### sql/schema/015_groups.sql, 036_fix_cascade_delete_user.sql, 037_force_password_change.sql
Added `-- +goose Up` and `-- +goose Down` annotations that were missing. Without them
`goose up` silently skips the files.

### vaultdrive_client/e2e/agent-key-lifecycle.spec.ts
Three test fixes:
1. `key_prefix` regex: `/^qx_ak_/` → `/^qxak_/` (matches actual `AGENT_KEY_PREFIX=qxak_`)
2. Filemon locator: `getByText(/^GET https?:\/\/[^/]+\/quantix\/...)` → `page.locator("pre").filter({ hasText: /\/api\/v1\/auth\/introspect/ })` — avoids strict-mode violation and port dependency
3. Filemon URL: dropped hardcoded `8090` and `/quantix/` path prefix (frontend uses `apiBasePath="/api"`)

### vaultdrive_client/tsconfig.e2e.json (new)
Added dedicated tsconfig for Playwright tests so `process.env` resolves without TS error.
`@types/node` was already installed; no new deps needed.

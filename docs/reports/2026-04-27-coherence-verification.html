Found in baseline 32 fail · 7 did not run

Almost the entire Playwright suite was failing at e2e/helpers/trust.ts:42 on the assertion getByText("Welcome to QuantiX Drive") after a successful registration. The Dashboard heading had been changed to a dynamic time-based greeting (Good {morning|afternoon|evening}, {firstName}.) in an upstream commit (ee6c0ca docs+fix: verify branch and harden trust flows). The E2E helper was not updated to match.

  • Change: replaced getByText("Welcome to QuantiX Drive") with getByRole("button", { name: "Open QuantiX Drive" }) — the login submit button that appears when registration succeeds and the form flips back to login mode. (handleRegister() doesn't navigate to Dashboard; it just sets isLogin = true and prefills the login form.)

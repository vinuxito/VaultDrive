The admin users and logs list strings in admin.tsx remain hardcoded in English. However, since the admin page is restricted to administrators and not general users, this is flagged as low immediate impact.
Medium Browser confirm() dialogs in Admin
Six browser `confirm()` modal loops still exist in the admin panel. While not as intrusive as standard `alert()` blocking, they should be phased out in favor of clean dialogs.

Step 5 of the roadmap (decomposing the 2114 lines files.tsx page component) is still pending. No E2E or unit issues were observed, but future developer velocity is throttled by this file size.

Rules after the split

  1. Features land upstream first. Clone QuantiX-Drive, branch, PR, merge to upstream main.
  2. ABRN-Drive syncs weekly. git fetch upstream && git merge upstream/main. Conflicts should only touch override files.
  3. ABRN hotfixes backport upstream first. If a bug is ABRN-only, fix on QuantiX-Drive anyway (the bug exists in the engine), then sync down.
  4. Never edit .env.abrn on the upstream. It belongs only to the ABRN overlay.
  5. Both repos run the full test suite in CI. QuantiX-Drive with its defaults, ABRN-Drive with its overlay applied.

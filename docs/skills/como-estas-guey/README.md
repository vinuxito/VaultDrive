# Como Estás, Güey? 💀

A generic operational-health skill for software systems.

It gives agents and applications a reusable contract for answering **“¿Cómo estás, güey?”** with evidence instead of a decorative green light.

Prime law: **A system must be able to say what condition it is in without pretending.**

Use `SKILL.md` as the installable skill definition. The skill is deliberately stack-agnostic.

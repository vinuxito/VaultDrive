## RELATE WITH CONFIDENCE

That skill asks which entities plausibly relate, why, what competes, and when to abstain.
The ladder asks whether the component applying that reasoning can deliver a bounded
outcome, respect the host, and help other consumers. Confidence in a candidate link
is not the operating maturity of the matcher. Neither grants authority to merge,
allocate, pay, post, or rewrite source identity.

Consume the relationship receipt with its evidence, counterevidence, uncertainties,
source versions, and policy boundaries. If it says “ambiguous,” passing the local task
may mean a useful human handoff, not forcing a match to improve completion statistics.

## CSI Filemón / NOBODY MOVE

When claims conflict with observations, CSI investigates the source of disagreement.
The ladder identifies missing capability and externalities. Preserve the affected scene
without freezing unrelated safe work or delaying urgent authorized containment.
A written hold is not an enforced hold. Review lenses are not independent witnesses.

## WAIT FASTER

Use it for independent work that can safely progress while another dependency waits.
The ladder checks whether that parallelism actually improves outcomes after coordination,
resource, and recovery costs. Worker count and constant activity are not evidence.
If no useful independent task remains, checkpoint and wait rather than spawn filler.

## ¿Cómo estás, güey?

Operational health supplies freshness, readiness, dependency status, workload, and
needed human attention. The ladder consumes those observations. A reachable endpoint
is not a complete business outcome. A temporarily unavailable dependency does not erase
a component's historical capabilities; it changes what is safe and supported now.

## Filemón Office

The host retains source authority and business meaning; Office provides consistent
opening, reading, navigating, citing, and return behavior. The ladder asks which exact
journeys are demonstrated, whether host boundaries survive, and whether the second host
gets the benefit without bespoke babysitting. A registered adapter or matching-looking
screenshot is not enough to award system leverage.

## Brenda's executive modal dock / Experiencia de Barrio

These shape a human-usable interface: context, consequence, reachable actions, useful
feedback, and a safe return. The ladder asks whether the pattern reduces real user and

## Human exceptions

An explicit owner exception can permit a particular action where policy allows. It does
not manufacture evidence, waive a forbidden tenant crossing, or certify reliability.
Record the actor, scope, reason, expiry, consequence, and relevant uncertainty. Never
self-sign a permission expansion because the ladder assessment looks impressive.

## A small composition example

A payment reference is ambiguous. Health verifies source freshness. RELATE WITH CONFIDENCE
returns two competing allocations. CSI is used only if a historical claim conflicts.
WAIT FASTER allows independent invoices to be reviewed. Office opens the source in place.
The ladder records that the matcher stopped safely and gave a useful handoff; it then
checks whether the full arrangement reduced central clarification work.

Not every case needs every skill. Use the smallest set that answers the actual question.
The common contract is: one source of authority per protected operation, traceable
observations, honest uncertainty, bounded work, and no invisible side effects.

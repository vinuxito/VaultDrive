# Changelog

## 1.0.0

Initial portable skill package. Preserves Phoenix/Filemón's four rung names and their
original meanings; adds cumulative scoped gates, authority separation, evidence limits,
coordination economics, host adaptation, incremental improvement, synthetic examples,
local consistency checks, and a browser-readable handbook.

No prior live application was modified, no production capability was certified, and
no runtime was installed as part of creating this release.

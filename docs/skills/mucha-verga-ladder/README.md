# 🪜 The Mucha Verga Ladder · v1.0.0
## Simple Steps for Systems

**Agency → local action. High agency → local results. Mucha verga → reliable cooperation.
No te mames → reusable capability that improves the whole without more micromanagement.**

This portable skill turns Phoenix and Filemón's four-rung idea into an operational
assessment and improvement method. It applies to a function, module, agent, workflow,
shared service, app, or a team's operating arrangement. It does not grade people.

The question is not “How do we make every agent autonomous?” It is “Which decisions
belong locally, which constraints must be shared, and what evidence shows the whole
system benefits?” The right target can be a small, reliable tool—not a fleet.

## Start here

Open [the offline handbook](INDEX.html) in a browser for the complete reading edition.
Agents should start with [SKILL.md](SKILL.md) and load only relevant references.
[Quickstart](QUICKSTART.md) gives the first prompt. [Installation](INSTALL.md) is manual.
[Verification](VERIFICATION.md) states exactly what was and was not tested.

Included: the core skill; twelve reference chapters; reusable markdown and JSON
templates; assessment and policy schemas; synthetic examples; a local contract checker;
automated tests; and live acceptance scenarios. The checker validates declared structure
and selected consistency rules. It does not run your systems, authenticate evidence,
certify safety, or grant authority.

## What makes it useful

A component may execute commands but fail to finish the task. It may finish locally
but leave someone else cleaning up. It may cooperate reliably yet still need a bespoke
operator for every new consumer. The ladder distinguishes these cases and points to
the next missing capability rather than prescribing “more AI.”

Every assessment is bound to a version, operating envelope, evidence window, and host.
A successful PDF reader does not confer a rung on an entire ERP. A successful synthetic
example does not certify production. A beautiful diagram earns no capability claim.

## What it deliberately refuses

No arbitrary agency percentages. No ranking by token consumption, charisma, confidence,
agent count, or hours worked. No automatic permission expansion. No copied sources
masquerading as independent corroboration. No “green” result achieved by excluding failures.
No “less coordination” achieved by dumping unpaid support work on a neighbor.

The ladder is an original practical framework, **not** a validated scientific maturity
scale. External sources support specific engineering practices, not the rung names or
an assertion that this framework has been scientifically established. See [Sources](SOURCES.md).

## Installation and execution footprint

There is no shell installer, Python installer, daemon, plugin registration, network
client, agent-spawner, account connection, or auto-update hook. Copy the reviewed folder
manually into a skill location configured by your runtime. Do not overwrite an existing
copy blindly. The optional checker uses Python 3.10+ and an already installed `jsonschema`.
No dependency installation happens automatically. No app or repository was changed by
creating this bundle.

**Barrio test:** “No nomás hagas tu chamba: hazla sin dejarle el cagadero al de al lado.
Y si puedes hacer que los demás también trabajen mejor, ahí sí: no te mames.”

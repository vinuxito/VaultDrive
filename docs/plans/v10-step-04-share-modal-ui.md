# Step 4: Invite & Share Modal UI

Implement the user interface components allowing folder owners to manage active shares.

## Interface

1. **Folder Share Trigger**:
   - Add a "Share Folder" option to context menus and actions list in the Folder sidebar or Folder lists.

2. **Share Modal**:
   - Input search autocomplete box allowing search of organization users.
   - Fetch target user's details, execute key wrapping, and submit share payload.
   - Display a list of active users with access to the folder and a "Revoke" button to delete their key envelopes.

## Why This Matters

A hackathon demo is a performance. The best product loses to the better performance every time. This script exists so that the demo is rehearsed, timed, and emotionally structured — not improvised.

## The Script

The full demo script lives at: [2026-05-22-step-10-demo-script.md](./2026-05-22-step-10-demo-script.md)

It follows a **5-beat narrative arc**:

| Beat | Time | Emotion | Action |
|------|------|---------|--------|
| 1 | 0-10s | "That looks expensive" | Landing page + hero |
| 2 | 10-25s | "It actually works" | Upload + encryption proof |
| 3 | 25-40s | "I can verify this" | Share link + ZK proof |
| 4 | 40-55s | "They thought of everything" | Agent keys + audit |
| 5 | 55-60s | "This is a hackathon?!" | Themes + i18n |

## Pre-Demo Checklist

- [ ] Demo account pre-registered (PIN set, 2-3 files uploaded)
- [ ] Browser: Chrome, incognito window ready
- [ ] Theme: Start on QuantiX (dark neon)
- [ ] Language: Start on English
- [ ] Network: Stable, backend running
- [ ] Screen: 1920×1080, zoom 100%
- [ ] Practice run completed (timed under 60s)
